== Description ==

Tema corporativo minimalista ("Kinetic Enterprise") construido con Bootstrap 5.
Incluye portada con secciones (hero, servicios, nosotros, ventajas, contacto),
plantillas de página, entrada, archivo y 404, menús, widgets de pie de página
y soporte del Personalizador para los datos de contacto.

== Installation ==

1. Sube la carpeta `empresa-theme` a `/wp-content/themes/`.
2. Activa el tema desde Apariencia > Temas.
3. Asigna un menú a la ubicación "Menú principal" en Apariencia > Menús.
4. Configura la dirección de contacto en Apariencia > Personalizar > Datos de contacto.
